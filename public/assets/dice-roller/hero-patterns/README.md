# Hero Patterns

87 unstyled SVG patterns by Steve Schoger, downloaded from the individual
"Download unstyled SVG" links at https://heropatterns.com/ on 2026-09-11.

Licensed under Creative Commons Attribution 4.0 International (CC BY 4.0):
https://creativecommons.org/licenses/by/4.0/

These SVG files are unmodified. The app composites the artwork at 25% opacity
over a solid background at runtime and applies the selected surface color.
The catalog is in `src/app/dice-roller/_constants/hero-patterns.json`.
